# Executive Dashboard

Run from the project root:

```bash
streamlit run dashboard/app.py
```

## Views

- **Executive pulse:** the smallest set of metrics that explains the system's current state.
- **Demand & inventory:** transfer ledger, replenishment pressure, stockouts, and explicit operating constraints.
- **Client intelligence:** value/risk map and behavioral profiles.
- **Clienteling:** consent-aware associate workspace with action filters and reasons.

The dashboard is intentionally unframed and restrained: four decision views, no decorative KPI overload, and no automatic outreach. All figures are derived or synthetic portfolio outputs and are labeled accordingly.
